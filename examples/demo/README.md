# Offline replay sample

Generated by `caerus demo` from the fictional profile, job and saved responses in
`skills/demo_data/`. All content is synthetic. These text artifacts demonstrate the
portable demo output; live runs generate DOCX/PDF letters. Metrics show observed
local latency for one example run, with zero network requests, tokens and cost.

The CLI also writes `application.json` and copies the three saved input files into
each new demo output directory. Run the demo to inspect those artifacts together.
